PROJECT DESCRIPTION (paste into "Description")
Kamiwa Journeys is a private Japan travel agency that wanted a site that feels like
opening a hand-folded paper gift rather than scrolling a brochure.

What I built
• A real-time 3D "paper world" hero in three.js: four dioramas (Tokyo, Kyoto,
  Nakasendō, a floating origami crane) built from flat-shaded geometry with soft
  shadows and paper-cut water terraces. No image assets — everything is procedural.
• A scroll-driven stage: the hero stays pinned across a 400vh track and each quarter
  swaps the scene, the copy and the scene rail with staggered pop-up transitions.
  Cursor parallax tilts the island.
• Nine responsive pages (home, destinations, destination detail, journeys, four-step
  planner, confirmation, about, journal, contact) from one component system: two
  typefaces, six paper colours, one button style.
• A four-step trip planner (who / season / what pulls you / contact): colour-coded
  season picker, kanji interest chips, a live "paper sheet" summary that re-folds with
  every pick, name and email validation, and a confirmation page that echoes the sheet
  back. Ready to POST to any CRM.
• Page-fold transitions between routes, staggered reveals, mobile menu, and a
  mobile layout where nothing is hidden — the diorama moves above the copy.

Stack: React, three.js, vanilla CSS (inline design tokens), Node-ready API layer.
Performance: 60 fps desktop, shadow maps clamped on mobile, 3D pauses when the
tab is in the background.
